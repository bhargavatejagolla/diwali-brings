# A Thousand Lights, One Wish

A cinematic, interactive 3D Diwali celebration dedicated to Dharvi Shravya.

## Experience Journey

- **01 / The First Light**: An interactive clay diya on reflective sacred waters.
- **02 / Rangoli of Wishes**: A radiant golden rangoli mandala surrounded by floating diyas.
- **03 / Garden of Light**: Palace courtyard lanterns floating under starry skies.
- **04 / A Quiet Wish**: An intimate heartfelt festive letter on golden handmade paper.
- **05 / Celestial Sky**: Interactive pyrotechnic celebration with customizable fireworks and wish releasing.

## Tech Stack

- **TanStack Start** (React 19)
- **Three.js** & **React Three Fiber** (`@react-three/fiber`, `@react-three/drei`, `@react-three/postprocessing`)
- **Tailwind CSS v4**
- **TypeScript**
